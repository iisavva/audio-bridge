# Audio Bridge

Приложение для Windows: принимает звук Android по Bluetooth и воспроизводит его вместе со звуком ПК через выбранные наушники или колонки.

```text
Android ── Bluetooth ──► Windows ──► наушники / колонки
                           ▲
                     звук приложений ПК
```

Используется встроенный Bluetooth-приёмник Windows (`AudioPlaybackConnection`, A2DP Sink). Windows смешивает входящий звук телефона с обычными звуковыми потоками ПК. Привязки к производителю или модели наушников нет.

## Возможности

- Выбор сопряжённого телефона и включение приёма одной кнопкой.
- Громкость телефона от 0 до 200% с программным усилением выше 100%.
- Плавное движение ползунка: аудиооперации выполняются отдельно от движения бегунка, промежуточные значения объединяются.
- Подготовка, чтение и освобождение A2DP-захвата выполняются в одном потоке WASAPI, включая остановку до запуска усиления.
- Автоматическое восстановление связи: повторные попытки через 2, 4, 8 и затем 15 секунд. Во время ожидания приёмник остаётся доступным для подключения с Android.
- Обнаружение обрыва по событиям Windows, повторная подготовка приёмника после сна и обновление его регистрации после нескольких неудач.
- Кнопка **Повторить подключение**, чтобы повторить попытку сразу, не дожидаясь таймера.
- Кнопка **Восстановить звук** доступна при открытом Bluetooth-соединении: полностью пересоздаёт аудиоприёмник и восстанавливает выбранную громкость телефона.
- При смене выхода звука Windows маршрут телефона пересоздаётся автоматически, если включено **Восстанавливать связь**. Обычная пауза в музыке не запускает переподключение.
- Работа в фоне: крестик, Alt+F4 и кнопка сворачивания скрывают окно в трей рядом с часами.
- Возврат окна двойным щелчком по значку или через пункт **Открыть**; полное завершение через **Выйти**.
- Остановка приёма без удаления Bluetooth-сопряжения.
- Русскоязычный интерфейс и сохраняемый журнал состояния соединения с кодами ошибок Windows.

Для работы не нужны учётная запись, интернет или установка виртуального аудиодрайвера.

## Требования

- Windows 10 версии 2004 или новее либо Windows 11.
- .NET Framework 4.8.
- Bluetooth-адаптер и драйвер с поддержкой приёма A2DP-аудио в Windows.
- Android-телефон, поддерживающий передачу мультимедиа по Bluetooth и сопряжённый с ПК.
- Аудиовыход Windows: проводные наушники, USB-гарнитура, наушники с радиопередатчиком или колонки.

Вывод в Bluetooth-наушники отдельно не проверялся. Возможность одновременно принимать звук телефона и передавать его в Bluetooth-наушники зависит от адаптера и драйвера.

## Сборка и запуск

Исходники собираются компилятором .NET Framework, входящим в Windows с установленным .NET Framework 4.8. Отдельный Windows SDK и загрузка NuGet-пакетов не требуются.

```powershell
git clone https://github.com/iisavva/audio-bridge.git
cd audio-bridge
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\AudioBridge.exe
```

Готовый файл `AudioBridge.exe` появится в корне проекта. Сборка использует только локальные компоненты Windows. Параметр `ExecutionPolicy Bypass` действует на процесс сборки и не меняет постоянную политику PowerShell.

Можно указать другой путь к EXE; каталог назначения должен существовать:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputPath .\tools\AudioBridge.exe
```

При обычном запуске права администратора не нужны. Перед пересборкой работающего EXE заверши приложение через пункт **Выйти** в меню значка в трее.

## Подключение телефона

1. Подключи наушники или колонки к ПК и выбери их выходом звука Windows. Если у игры или программы есть собственный выбор выхода, укажи нужное устройство и там.
2. В Windows открой **Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth**.
3. Выполни сопряжение Android с ПК и подтверди одинаковый код на обоих устройствах.
4. Открой Audio Bridge, выбери телефон и нажми **Принимать звук телефона**. Если телефон не появился, нажми **Обновить**.
5. В настройках Bluetooth Android для этого ПК включи **Мультимедиа / Звук мультимедиа**, если такой переключатель доступен. В выборе медиавыхода Android укажи ПК.
6. Запусти музыку или видео на телефоне и одновременно звук на ПК.

В этой схеме телефон передаёт звук компьютеру. Если он также активно подключён непосредственно к наушникам или другой колонке, проверь, что выбран именно ПК. Для гарнитуры с USB-радиопередатчиком используй её подключение к компьютеру.

Надпись **Аудиосоединение открыто** подтверждает открытие соединения. Чтобы проверить слышимость, включи воспроизведение на телефоне.

## Громкость

| Регулятор | Что меняет |
| --- | --- |
| **0–100%** | Громкость отдельного потока Android в микшере Windows. |
| **101–200%** | Программное усиление звука Android. 150% — коэффициент амплитуды ×1,5, 200% — ×2. |

В приложении есть только регулятор телефона. Общая громкость Windows и уровни приложений ПК не изменяются.

Ползунок телефона появляется после обнаружения его аудиопотока. Если он недоступен, запусти музыку или видео на Android и подожди несколько секунд.

Усиление включается только при выборе значения выше 100%. Для него приложение открывает отдельный A2DP-вход выбранного телефона через Windows Core Audio и подаёт данные в AudioGraph. Исходное воспроизведение телефона временно заглушается, чтобы не было двойного звука. При возврате к 100% и ниже обычное воспроизведение восстанавливается. Подготовленный усилитель сохраняется до отключения телефона, поэтому переходы через 100% не создают его заново при каждом движении.

Если драйвер не предоставляет отдельный A2DP-вход или его формат не поддерживается, приложение сообщает об ошибке и возвращается к обычному диапазону 0–100%. Микрофон гарнитуры и общий звук ПК не используются для усиления. Усиление может добавить задержку; на громких записях возможны искажения.

Ползунок обновляет положение и процент сразу, а значения громкости применяются с объединением промежуточных изменений не чаще 25 раз в секунду. Во время подготовки усилителя ползунок остаётся доступным; применяется последнее выбранное значение. Windows может сохранять обычную громкость аудиосессии между подключениями.

Поток телефона определяется по имени выбранного устройства и метке `A2DP SNK`. Если драйвер обозначает его иначе или обнаружены несколько совпадающих потоков, ползунок остаётся недоступным, чтобы не изменять громкость других приложений.

## Ограничения

- Передаётся звук, который Android направляет на ПК как мультимедиа. Передача абсолютно всех сигналов телефона не гарантируется: будильники, уведомления и системные звуки могут иметь отдельные правила маршрутизации.
- Телефонные и интернет-звонки не передаются этим A2DP-приёмником. Микрофон гарнитуры также не передаётся на Android.
- Обычные телефонные звонки можно отдельно настроить в приложении Microsoft **Связь с телефоном → Вызовы**. Это отдельная функция Microsoft; её работа не входит в Audio Bridge. «Связь с телефоном» не поддерживает ретрансляцию звонков в Bluetooth-гарнитуру.
- Android или приложение на телефоне может приостанавливать музыку во время звонков. Audio Bridge не меняет правила аудиофокуса Android.
- Bluetooth добавляет задержку к звуку телефона. Звук приложений ПК продолжает идти непосредственно в выбранный аудиовыход.
- Эксклюзивный режим отдельных программ Windows может мешать одновременному воспроизведению нескольких источников.

## Если соединение или звук не работают

**Телефон сопряжён, но показывает «Отключено».** Сопряжение и активное аудиосоединение — разные состояния. Сначала включи приём в Audio Bridge и запусти воспроизведение на Android. Не нужно удалять сопряжение при каждом таком статусе.

**Телефон не найден.** Проверь Bluetooth и сопряжение именно с ПК, затем нажми **Обновить**. Если источник остаётся недоступным, проверь поддержку A2DP Sink адаптером и драйвером.

**Подключение срабатывает не с первого раза.** Оставь включённым **Восстанавливать связь**: приложение повторяет попытки самостоятельно и сохраняет доступность приёмника для телефона. Для немедленной попытки нажми **Повторить подключение**. Если ошибка повторяется, открой **Журнал подключения** через меню значка в трее или **Открыть файл журнала** правой кнопкой в поле журнала. Файл `%LOCALAPPDATA%\AudioBridge\connection.log` содержит время, этап подключения, результат `OpenAsync` и доступный код ошибки Windows. При достижении 512 КиБ сохраняется одна предыдущая копия; содержимое звука не записывается, журнал никуда не отправляется. После **Остановить** автоматические попытки прекращаются.

**Соединение открыто, но звука нет.** Проверь медиавыход Android, переключатель мультимедиа для ПК, громкость телефона и выбранный аудиовыход Windows.

Если телефон отправляет музыку на ПК, а в наушниках тишина, нажми **Восстановить звук**. Статус Bluetooth показывает состояние соединения, а не наличие слышимого звука. Приложение запишет состояние аудиосессии, её громкость, mute, мгновенный уровень сигнала и текущий маршрут, затем пересоздаст приёмник. Громкость сохраняется; при значении выше 0% снимается отключение звука только с потока телефона. Это способ восстановить поток и собрать диагностику; открытое соединение без звука само по себе не определяет причину сбоя. Аудиозапись не создаётся.

**Звук прерывается.** Поднеси телефон ближе, проверь другие активные аудиоподключения Android. Для USB-адаптера Bluetooth может помочь удлинитель, позволяющий расположить его дальше от портов USB 3.0 и других передатчиков 2,4 ГГц.

**Окно исчезло после нажатия крестика.** Приложение продолжает работать в трее. Найди значок Audio Bridge рядом с часами; он может находиться в меню скрытых значков. Двойной щелчок открывает окно, пункт **Выйти** полностью завершает приёмник.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `AudioBridge.cs` | Окно WinForms, Bluetooth-подключение, восстановление связи и работа в трее. |
| `PhoneReceiver.cs` | Жизненный цикл приёмника, повторные попытки, события состояния и сохраняемый журнал ошибок. |
| `AudioMixer.cs` | Управление громкостью и отключением звука отдельной аудиосессии телефона. |
| `PhoneAmplifier.cs` | Усиление 101–200% через AudioGraph и восстановление исходного воспроизведения. |
| `NativePhoneCapture.cs` | Захват скрытого A2DP-входа выбранного телефона через Windows Core Audio. |
| `build.ps1` | Сборка приложения средствами Windows. |
| `tools/Probe.cs` | Диагностика обнаружения совместимых Bluetooth-источников. |
| `tools/MixerProbe.cs` | Чтение уровней и состояния аудиосессий Windows. |
| `tests/Program.cs` | Проверки восстановления соединения с имитацией ошибок, выбора источника и усиления на синтетических аудиоданных. |

Скомпилированные EXE и временные файлы сборки исключены из Git.

## Проверка

На Windows 11 проверены сборка, обнаружение сопряжённого Android, открытие A2DP-соединения и воспроизведение через наушники с USB-радиопередатчиком. Подтверждены отдельная регулировка громкости телефона и работа усиления выше 100%. После закрытия окна процесс и активная аудиосессия телефона сохраняются.

Автоматические проверки обрабатывают синтетические данные внутри AudioGraph без вывода тестового звука в наушники. Проверяются коэффициенты 0%, 50%, 100%, 150% и 200% и выбор только A2DP-источника нужного телефона.

Проверки подключения имитируют тайм-аут, входящее восстановление, обрыв, недоступность адаптера, повторные неудачи, остановку во время подключения и запоздалые события. Проверяется, что попытки не идут параллельно и приёмник остаётся доступным между ними. Их можно запустить отдельно командой `AudioBridge.Tests.exe --connection` без Bluetooth-устройства.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -BuildTests
.\tests\AudioBridge.Tests.exe
```

Для проверки AudioGraph нужен доступный аудиовыход Windows. Диагностический запуск `AudioBridge.Tests.exe --inputs` выводит обнаруженные аудиовходы; `--capture-id <id>` проверяет открытие конкретного A2DP-входа без воспроизведения.

`AudioBridge.Tests.exe --phone-status` читает состояние, громкость, mute и мгновенный уровень аудиосессии телефона на текущем выходе Windows. Значение 0 само по себе не отличает паузу от сбоя; автоматическое восстановление по тишине не выполняется.

`AudioBridge.Tests.exe --phone-signal "имя телефона"` на 2,5 секунды открывает только отдельный A2DP-вход указанного телефона и выводит количество полученных байтов и пиковый уровень. Также проверяет завершение потока и освобождение WASAPI после остановки. Звук не записывается и не воспроизводится; обычный микрофон не используется. Проверку нужно запускать во время воспроизведения на телефоне. `--capture-id <id>` дополнительно проверяет освобождение захвата без запуска чтения и повторное безопасное выполнение `Dispose`.

Автовосстановление после реального обрыва из-за радиопомех, другие Bluetooth-адаптеры и вывод в Bluetooth-наушники отдельно не проверялись.
