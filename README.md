# Audio Bridge

Приложение для Windows: принимает звук Android по Bluetooth и воспроизводит его вместе со звуком ПК через выбранные наушники или колонки.

```text
Android ── Bluetooth ──► Windows ──► наушники / колонки
                           ▲
                     звук приложений ПК
```

Используется встроенный Bluetooth-приёмник Windows (`AudioPlaybackConnection`, A2DP Sink). Windows смешивает входящий звук телефона с обычными звуковыми потоками ПК. Привязки к производителю или модели наушников нет.

## Возможности

- Выбор сопряжённого телефона и включение приёма одной кнопкой.
- Отдельная громкость телефона и общая громкость аудиовыхода Windows.
- Автоматические попытки восстановления соединения с интервалом не менее 15 секунд.
- Работа в фоне: крестик, Alt+F4 и кнопка сворачивания скрывают окно в трей рядом с часами.
- Возврат окна двойным щелчком по значку или через пункт **Открыть**; полное завершение через **Выйти**.
- Остановка приёма без удаления Bluetooth-сопряжения.
- Русскоязычный интерфейс и журнал состояния соединения.

Для работы не нужны учётная запись, интернет или установка виртуального аудиодрайвера.

## Требования

- Windows 10 версии 2004 или новее либо Windows 11.
- .NET Framework 4.8.
- Bluetooth-адаптер и драйвер с поддержкой приёма A2DP-аудио в Windows.
- Android-телефон, поддерживающий передачу мультимедиа по Bluetooth и сопряжённый с ПК.
- Аудиовыход Windows: проводные наушники, USB-гарнитура, наушники с радиопередатчиком или колонки.

Вывод в Bluetooth-наушники отдельно не проверялся. Возможность одновременно принимать звук телефона и передавать его в Bluetooth-наушники зависит от адаптера и драйвера.

## Сборка и запуск

Исходники собираются компилятором .NET Framework, входящим в Windows с установленным .NET Framework 4.8. Отдельный Windows SDK и загрузка NuGet-пакетов не требуются.

```powershell
git clone https://github.com/iisavva/audio-bridge.git
cd audio-bridge
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\AudioBridge.exe
```

Готовый файл `AudioBridge.exe` появится в корне проекта. Сборка использует только локальные компоненты Windows. Параметр `ExecutionPolicy Bypass` действует на процесс сборки и не меняет постоянную политику PowerShell.

Можно указать другой путь к EXE; каталог назначения должен существовать:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputPath .\tools\AudioBridge.exe
```

При обычном запуске права администратора не нужны. Перед пересборкой работающего EXE заверши приложение через пункт **Выйти** в меню значка в трее.

## Подключение телефона

1. Подключи наушники или колонки к ПК и выбери их выходом звука Windows. Если у игры или программы есть собственный выбор выхода, укажи нужное устройство и там.
2. В Windows открой **Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth**.
3. Выполни сопряжение Android с ПК и подтверди одинаковый код на обоих устройствах.
4. Открой Audio Bridge, выбери телефон и нажми **Принимать звук телефона**. Если телефон не появился, нажми **Обновить**.
5. В настройках Bluetooth Android для этого ПК включи **Мультимедиа / Звук мультимедиа**, если такой переключатель доступен. В выборе медиавыхода Android укажи ПК.
6. Запусти музыку или видео на телефоне и одновременно звук на ПК.

В этой схеме телефон передаёт звук компьютеру. Если он также активно подключён непосредственно к наушникам или другой колонке, проверь, что выбран именно ПК. Для гарнитуры с USB-радиопередатчиком используй её подключение к компьютеру.

Надпись **Аудиосоединение открыто** подтверждает открытие соединения. Чтобы проверить слышимость, включи воспроизведение на телефоне.

## Громкость

| Регулятор | Что меняет |
| --- | --- |
| **Телефон** | Только поток Android в микшере Windows; уровни приложений ПК сохраняются. |
| **Общая громкость** | Общую громкость текущего аудиовыхода Windows: и ПК, и телефона. |

Ползунок телефона появляется после обнаружения его аудиопотока. Если он недоступен, запусти музыку или видео на Android и подожди несколько секунд.

Приложение считывает текущие уровни Windows и не повышает их автоматически. Windows может сохранять громкость аудиосессии между подключениями.

Поток телефона определяется по имени выбранного устройства и метке `A2DP SNK`. Если драйвер обозначает его иначе или обнаружены несколько совпадающих потоков, ползунок остаётся недоступным, чтобы не изменять громкость других приложений.

## Ограничения

- Передаётся звук, который Android направляет на ПК как мультимедиа. Передача абсолютно всех сигналов телефона не гарантируется: будильники, уведомления и системные звуки могут иметь отдельные правила маршрутизации.
- Телефонные и интернет-звонки не передаются этим A2DP-приёмником. Микрофон гарнитуры также не передаётся на Android.
- Обычные телефонные звонки можно отдельно настроить в приложении Microsoft **Связь с телефоном → Вызовы**. Это отдельная функция Microsoft; её работа не входит в Audio Bridge. «Связь с телефоном» не поддерживает ретрансляцию звонков в Bluetooth-гарнитуру.
- Android или приложение на телефоне может приостанавливать музыку во время звонков. Audio Bridge не меняет правила аудиофокуса Android.
- Bluetooth добавляет задержку к звуку телефона. Звук приложений ПК продолжает идти непосредственно в выбранный аудиовыход.
- Эксклюзивный режим отдельных программ Windows может мешать одновременному воспроизведению нескольких источников.

## Если соединение или звук не работают

**Телефон сопряжён, но показывает «Отключено».** Сопряжение и активное аудиосоединение — разные состояния. Сначала включи приём в Audio Bridge и запусти воспроизведение на Android. Не нужно удалять сопряжение при каждом таком статусе.

**Телефон не найден.** Проверь Bluetooth и сопряжение именно с ПК, затем нажми **Обновить**. Если источник остаётся недоступным, проверь поддержку A2DP Sink адаптером и драйвером.

**Соединение открыто, но звука нет.** Проверь медиавыход Android, переключатель мультимедиа для ПК, громкость телефона и выбранный аудиовыход Windows.

**Звук прерывается.** Поднеси телефон ближе, проверь другие активные аудиоподключения Android. Для USB-адаптера Bluetooth может помочь удлинитель, позволяющий расположить его дальше от портов USB 3.0 и других передатчиков 2,4 ГГц.

**Окно исчезло после нажатия крестика.** Приложение продолжает работать в трее. Найди значок Audio Bridge рядом с часами; он может находиться в меню скрытых значков. Двойной щелчок открывает окно, пункт **Выйти** полностью завершает приёмник.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `AudioBridge.cs` | Окно WinForms, Bluetooth-подключение, восстановление связи и работа в трее. |
| `AudioMixer.cs` | Управление аудиосессиями и общей громкостью через Windows Core Audio. |
| `build.ps1` | Сборка приложения средствами Windows. |
| `tools/Probe.cs` | Диагностика обнаружения совместимых Bluetooth-источников. |
| `tools/MixerProbe.cs` | Чтение уровней и состояния аудиосессий Windows. |

Скомпилированные EXE и временные файлы сборки исключены из Git.

## Проверка

На Windows 11 проверены сборка, обнаружение сопряжённого Android, открытие A2DP-соединения и воспроизведение через наушники с USB-радиопередатчиком. Подтверждены отдельная регулировка громкости телефона и общая громкость выхода Windows. После закрытия окна процесс и активная аудиосессия телефона сохраняются.

Автовосстановление после реального обрыва из-за радиопомех, другие Bluetooth-адаптеры и вывод в Bluetooth-наушники отдельно не проверялись.
